About this dashboard

Live unpaid-invoice dashboard for all 4 companies (SOR · TCCS · TPM · TF), pulled straight from Xero's Awaiting Payment list. It updates itself on weekdays at ~9am & ~1pm (Sydney) — the time of the last update is shown at the top right.

Views

Rank by count / $ — sites ranked by number of unpaid invoices or by amount owed; click a row to see its invoices.
🔴 Terminated — the terminated-customer list comes from each team's “Quote Termination NEW” Excel (Termination sheet) — what you record there becomes this list. On every update each customer is checked against Xero: red = still owing (amount shown), green ✓ = paid in full. Sorted by termination date.
📋 Payment Review — groups unpaid invoices by customer and flags problems automatically.

Payment Review categories

Skipped Payment an unpaid month followed by paid months — the customer likely missed one invoice (contact first).
3+ months three or more months in a row unpaid, up to now.
2+ months last unpaid invoice is 2+ months old with nothing newer — service may have ended.
Recent only the last 1–2 months unpaid — normal cycle, listed so nothing is missed.

Filters (Payment Review)

SOR by invoice reference: Work (ww teams) · Commercial · S2 · S3 · S4 · S5 (each incl. its gardening refs).
TCCS / TPM by customer name: Home = names starting with “..”, Commercial = everyone else.
TF: Retail = customers marked with “_”. Default is All; the search box finds customers, “Extra ref filter” accepts any reference.

Buttons

Excel downloads the current list · click an email to write to the customer · open in Xero jumps to Xero · Download PDFs saves ticked invoices (needs Xero login + the XERO bar) · Statement PDF (customers with 2+ invoices) saves that customer’s outstanding statement as one PDF (same requirements).

이 대시보드 안내

4개 법인(SOR · TCCS · TPM · TF)의 미납 인보이스를 Xero의 Awaiting Payment에서 바로 가져와 보여주는 페이지입니다. 평일 오전 9시쯤·오후 1시쯤(시드니) 자동으로 갱신되고, 마지막 갱신 시각은 오른쪽 위에 표시됩니다.

화면 종류

Rank by count / $ — 미납 건수/금액 순위. 줄을 누르면 인보이스 목록이 펼쳐집니다.
🔴 Terminated — 해지 명단은 각 팀 폴더의 "Quote Termination NEW" 엑셀(Termination 시트)에서 온 것 — 여러분이 그 시트에 적는 내용이 곧 이 명단입니다. 갱신 때마다 명단의 고객을 Xero와 대조해서, 미납이 남아 있으면 빨강(금액 표시), 없으면 초록 ✓ Paid. 해지일 최신순 정렬.
📋 Payment Review — 고객별로 미납 월을 분석해 문제를 자동 분류합니다.

Payment Review 분류

Skipped Payment 미납 달 다음에 결제된 달이 있음 — 한 달을 건너뛰었을 가능성 (가장 먼저 연락).
3+ months 지금까지 3달 이상 연속 미납.
2+ months 마지막 미납이 2달 이상 전이고 그 후 인보이스 없음 — 서비스 종료 확인 필요.
Recent 최근 1~2달만 미납 — 정상 사이클, 누락 없게 표시.

필터 (Payment Review)

SOR 인보이스 reference로 검색: Work(ww팀) · Commercial · S2 · S3 · S4 · S5 (각 팀의 가드닝 ref 포함).
TCCS / TPM 고객 이름으로: Home = 이름이 ".."로 시작, Commercial = 나머지 전부.
TF: Retail = 이름에 "_" 표시 있는 고객. 기본은 All, 검색창 = 고객 이름, Extra ref filter = reference 직접 입력.

버튼

Excel = 현재 목록 다운로드 · 이메일 클릭 = 바로 메일 쓰기 · open in Xero = Xero로 이동 · Download PDFs = 체크한 인보이스 PDF 저장 (Xero 로그인 + XERO 바 필요) · Statement PDF = 인보이스 2개 이상인 고객에 표시 — 그 고객의 미납 statement 전체를 PDF 한 장으로 저장 (같은 조건).
